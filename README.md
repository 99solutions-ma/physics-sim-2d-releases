# Physics Sim 2D

Installers and automatic updates of **Physics Sim 2D**, the 2D mechanics
simulator by 99 Solutions. This repository holds downloads only; it has no
source code.

## Download

Open the [latest release](https://github.com/99solutions-ma/physics-sim-2d-releases/releases/latest):

- **macOS** (Apple silicon and Intel): the `.dmg` disk image. Open it and
  drag the app into Applications.
- **Windows**: the `-setup.exe` installer (or the `.msi`).

## Updates

Once installed, the app checks for a newer version once a day and offers
to update itself (« ? › À propos › Rechercher des mises à jour » checks
now). Updates are signed: the app only installs packages signed by
99 Solutions.
